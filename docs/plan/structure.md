Notes:

- Names without an extension in the tree are kebab-case `.ts` / `.tsx` files (`queue-list` → `queue-list.tsx`).
- Tests are colocated with the file they test (`queue-list.test.tsx`, `queue-service.int.test.ts`); they are not listed in the tree.
- A feature folder without subfolders (`moderation-form`, `mod-log`, …) keeps its files flat.
